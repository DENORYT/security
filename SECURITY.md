# Security Policy

## Supported scope

This is a learning and portfolio repository. Issues in the current `main` branch are in scope, especially unsafe defaults, secret disclosure through scanner output, and any regression that violates [SAFETY.md](SAFETY.md).

## Reporting

Please do **not** open a public issue with exploit details, credentials, or personally identifiable information. Instead, contact the repository owner through GitHub's private security reporting feature (if enabled) or a private channel listed on the repository profile.

Include:

- a concise description of the issue,
- affected file and revision,
- minimal safe reproduction steps, and
- suggested mitigation if known.

## Response expectations

Reports are triaged privately. Do not test against systems you do not own or have explicit permission to assess.
