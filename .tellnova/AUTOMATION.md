# Tellnova Safe Maintenance Automation

This repository has a user-authorized Tellnova recurring maintenance schedule named **Portfolio safe maintenance**. It runs every 24 hours with overlap skipped and latest-only catch-up. The active schedule definition generated by Tellnova is versioned at [`.pi/subagents/schedules/99c6ec4f/schedule.json`](../.pi/subagents/schedules/99c6ec4f/schedule.json); transient run events remain local runtime state and are not committed.

## What the scheduled worker may do

1. Work only in this repository and read [SAFETY.md](../SAFETY.md) first.
2. Make small, defensive, documented improvements to these four projects.
3. Keep the C2 Training Lab offline-only; it must never gain networking, host-control, process, credential, or instruction-execution capability.
4. Run all validation gates:
   - `python scripts/validate.py`
   - `git diff --check` for project files (Tellnova runtime state is excluded and never staged by the guard)
   - `python -m projects.pipeline_exposure .github --fail-on high`
   - `python scripts/safe_maintenance.py --check` (also scans every changed text file, including source and documentation, for high-severity exposure indicators)
5. If and only if all gates pass and there are substantive safe changes, invoke the guarded command:

   ```bash
   python scripts/safe_maintenance.py --commit --push --message "chore(maintenance): validated portfolio updates"
   ```

## Fail-closed rules

The worker must **not** commit or push when there are failing tests, merge conflicts, any pre-existing staged change (including Tellnova runtime state), secrets or sensitive file names, uninspectable/oversized changed files, high-severity findings in changed files or CI/CD configuration, safety-invariant violations, or no source change. It never force-pushes, rewrites history, creates releases, changes Git remotes, injects credentials, or bypasses branch protections.

The guard only pushes to the configured GitHub `origin` after creating a validated local commit. A missing credential or a rejected remote push is reported as a failure; it is not retried by weakening safeguards.

## Control

Use Tellnova's scheduled-run controls to pause, resume, inspect history, or delete the schedule. The schedule performs no work outside this repository. Human review remains appropriate for changes with architectural or safety impact.
